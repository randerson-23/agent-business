# Share note

Links to /this-weekend/, which always shows the coming weekend, so this note works any day of the week.

Paste into a text or an email. Plain text; the link carries `utm_source=friend&utm_campaign=seed` so Buttondown's tags count the signups.

## If you're writing to someone in Arlington Heights

```text
I've been building a free weekly email of what's on this weekend in Arlington Heights and nearby. Library, park district and village stuff, one email on Thursdays. Here's what's on this weekend: https://withintenmiles.com/this-weekend/?utm_source=friend&utm_campaign=seed If it's useful, you can sign up near the top.
```
